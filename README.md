# ps1-tim-tool
Command-line converter between PNG/JPG/BMP/TGA/WebP and Sony's official TIM texture format for the original PlayStation. Supports all 4 real TIM pixel formats (4/8/16/24-bit), VRAM/TPAGE/CLUT ID placement, multi-palette recoloring, dithering, batch conversion, and TIM verification/diffing. Pure Python, no dependencies beyond Pillow.
